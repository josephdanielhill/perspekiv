2026-08-16

Models Used

Tools Used

Interesting Facts

  • Built as the first project under Perspektiv – the agency itself, dogfooded.
  • Logo designed with Leckerli One (Google Fonts), ruby red dot baked into PNG.
  • Zero JavaScript on the page – pure HTML + CSS, responsive.
  • Deployed via GitHub Actions + Pages, custom domain on SquareCircleTriangle.

The first project shipped under the Perspektiv banner. A single-page landing site
that communicates the agency's philosophy: AI-native creative work that looks
intentional and reads like it took no effort.

The type system pairs a custom logo (Leckerli One + Nunito) with Ubuntu body text
across the page. Ruby red dot on the 'i' became the brand's signature mark.
